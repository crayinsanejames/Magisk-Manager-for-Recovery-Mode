# Apatch-KernelSU-Magisk Manager for Recovery Mode (mm

Easily manage your **Magisk/Apatch and KernelSU Modules** from a terminal session in your custom recovery! *(e.g. [TWRP](https://twrp.me/))*

## Features list
- Automatically fix magisk.img (e2fsck -fy)
- List installed modules
- Toggle
  - Core only mode
  - Magic mount
  - Disable
  - Remove


## Prerequisits
- **TWRP** or another custom recovery with terminal session suppor

# Apatch KernelSU Magisk Manager for Recovery Mode (mm)

Easily manage your **Magisk KernelSU Apatch Modules** from a terminal session in your custom recovery! *(e.g. [TWRP](https://twrp.me/))*

## Features list
- Automatically fix magisk.img (e2fsck -fy)
- List installed modules
- Toggle
  - Core only mode
  - Magic mount
  - Disable
  - Remove


## Prerequisite
- **Magisk** v19.0 - v28.X (Maybe not though un tested without magisk"
- **TWRP** or another custom recovery with terminal session support

## Setup
Install in a root management app or recovery like TWRP.
